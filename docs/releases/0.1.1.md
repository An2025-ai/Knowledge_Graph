# Brand Atlas 0.1.1 更新说明

发布日期：2026-09-09

## 本版本解决的问题

### 1. 聊天无法理解“总结知识库”类问题

当用户询问“你是否知晓数据库中的内容”“总结当前知识库”或“有哪些产品”时，旧检索只做完整字符串匹配，容易返回空上下文，导致 LLM 误以为本地没有资料。

0.1.1 增加了受控的本地概览检索：

- 知识库概览问题返回少量实体、关系和陈述；
- 产品、能力、客户和行业问题按实体类型筛选；
- 关系以 `主体 -[关系]-> 客体` 形式提供给 LLM；
- 普通无关问题不会自动倾倒整库。

### 2. 版本号不一致

以下组件已统一为 `0.1.1`：

- Tauri 应用；
- Rust 桌面包；
- Desktop npm 包；
- Frontend npm 包；
- Backend API；
- 界面版本显示。

### 3. 清理旧版测试和文档

旧 PostgreSQL/Neo4j 运行时专属的测试和文档已移除，新版 `shared/` 领域能力测试迁移到 `tests/unit/`。`legacy/` 目录本身未修改。

## 验证结果

- Python 全量测试：73/73 通过；

- Rust Cargo Release 构建：通过；
- PyInstaller Sidecar 构建：通过；
- Tauri NSIS 安装包构建：通过。

安装包压缩文件：

```text
dist/BrandAtlas-0.1.1-windows-x64.zip
```

## 已知限制

- 安装版仍默认使用 `%LOCALAPPDATA%\\BrandAtlas\\database\\knowledge.db`，不会自动读取项目目录数据库；
- 当前图谱仍是 SQLite 节点/关系读取和基础 SVG 展示，尚未加入多跳遍历、PageRank、社区发现或 GraphRAG；
- 概览检索目前是有限关键词策略，后续可替换为语义或向量检索。
